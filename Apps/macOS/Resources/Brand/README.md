# Aava identity

The Aava mark is a rounded capital A: a dark ink arch with an integrated periwinkle wave crossbar. The icon uses a cool-white tile and generous transparent margin.

| Color | Value |
|---|---|
| Ink | #262A36 |
| Cool white | #F6F7FC |
| Pale periwinkle | #E6E9F5 |
| Periwinkle | #A7B4FF |
| Secondary text | #606576 |

`LetterA.png` and `AppIcon.png` are 1254 × 1254 RGBA raster masters created with image-generation tools. `AppIcon.icns` contains native 16–1024 pixel representations exported by `scripts/build-icons.py`.

The app loads and shares the mark through `Brand.swift`. The brief native welcome animation respects Reduce Motion. Personal space colors remain independent of the core brand palette.
