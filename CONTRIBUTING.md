# Contributing

Aava is in early development. Reproducible bug reports and feedback are welcome. Check the preview limitations before filing compatibility issues.

For local work, follow [Building Aava](docs/public/BUILDING.md), run `swift test`, and explain how a change was verified. Keep engine changes separate from UI changes where practical. Avoid adding website rendering dependencies to the native shell.

Do not commit profiles, credentials, cookie databases, local logs, signing keys, provisioning files or personal screenshots. Use synthetic accounts and fixtures in tests. Follow the existing per-space isolation and reduced-motion behavior.

The project has not selected an open-source contribution license yet. Discuss substantial code contributions with the maintainers before submitting them.
