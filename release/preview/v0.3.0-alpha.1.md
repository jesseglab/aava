# Aava 0.3.0-alpha.1 — A little more room to browse

The first Aava developer preview from Geeklab: an Arc-inspired native Mac browser with personal spaces, a compact sidebar and a separate place for AI-controlled browsing.

![Aava](https://raw.githubusercontent.com/jesseglab/aava/main/docs/media/cover.svg)

## In this preview

- Vertical tabs, nested saved folders, one/two-column favorite tiles and history/archive search.
- Independent space profiles, PIN access locks, color/media backgrounds and optional glass.
- Arc spaces import plus bookmarks, history, extension restore lists and optional cookie transfer.
- Isolated, viewable Mini control with a temporary profile, take-over and stop controls.
- Downloads tray, tidy/clean actions, GitHub folder configuration and same-domain link preferences.
- Drag past half the minimum sidebar width to collapse; reopen at a usable width.

## Requirements and package status

**Apple Silicon · macOS 14+ · developer preview.** The attached ZIP is a local development build. It is **not notarized, not signed for general distribution, and not approved for the Mac App Store**. Build from source using the [build guide](https://github.com/jesseglab/aava/blob/main/docs/public/BUILDING.md) or wait for a distribution-signed release if macOS cannot verify it. Do not disable macOS security protections.

The SHA-256 file covers the ZIP. A source snapshot is available from the tag. No private profiles or credentials are included.

## Verification

93 core tests pass. Native synthetic checks cover the sidebar gesture, import UI and cookie transfer/isolation/persistence. See the [preview status](https://github.com/jesseglab/aava/blob/main/docs/public/PREVIEW-STATUS.md) for the full boundary of what has been tested.

## Known limitations

Chrome extension compatibility and real Meet/Teams calls are still being validated. Extension import creates a restore list, not automatic installation. Real account migration, production browser security/update infrastructure and performance comparisons are not signed off. iPhone/iPad is a later phase.

Aava is independent of The Browser Company and is not an official Arc continuation.
