# Aava 0.3.0-alpha.2 — Room to browse

A native Mac browser by Geeklab, with an Arc-inspired sidebar, independent spaces and an isolated Mini workspace for AI control.

## Familiar, with a few new possibilities

- Vertical tabs, nested saved folders, configurable favorite tiles, and searchable history/archive.
- Independent Chromium profiles for each space, image/GIF backgrounds, color controls and optional glass.
- PIN-locked spaces with idle locking and stay-unlocked options. PIN locks protect UI access; they are not full at-rest encryption.
- Arc spaces import, bookmark/history migration, an extension restore list and optional supported cookie transfer. Some accounts require signing in again; passkeys do not transfer.
- An isolated, viewable Mini session for AI control while you continue browsing.
- Downloads tray, tidy/clean actions, GitHub folder configuration and same-domain link preferences.
